# coffee

A Claude Code plugin that keeps the Mac awake with `caffeinate`.

## What it gives you

### `coffee:coffee`

- **coffee** starts `caffeinate -dims` detached, so it outlives the session: display, idle, disk and system sleep
  are all blocked.
- **coffee 2h**, **coffee 30m**, **coffee 1h30m** keep the Mac awake for that long.
- **decaf** or **coffee off** stops it. **coffee status** says whether it runs and for how long.

macOS only.
